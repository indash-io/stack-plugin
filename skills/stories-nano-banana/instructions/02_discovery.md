# 02 — Discovery

Trabajo silencioso. **No hablás con el user en este paso.** Procesás la URL y la imagen para armar el brief interno que después usás en Decisions y Concept.

---

## Sub-paso 2A: Scrapeo de la URL

### Qué extraer (en este orden de prioridad)

1. **Nombre exacto del producto** — tal como aparece en la página. No lo abrevies ni lo modifiques.
2. **Descripción principal** — el "qué es" en 1-2 oraciones.
3. **Beneficios clave** — los 3-5 que la marca destaca en bullets, badges o sección de features.
4. **Target / para quién es** — si la página lo dice explícito (ej: "para piel sensible", "para hombres mayores de 30").
5. **Precio** — para entender posicionamiento (premium / mid / accesible).
6. **Categoría** — skincare, fragancia, apparel, food, decor, etc.
7. **Tono de la copy del e-commerce** — cómo escribe la marca: técnico, emocional, minimalista, hablado, etc.
8. **Reviews destacadas** (si están visibles) — para detectar lenguaje real del cliente y posibles hooks.
9. **Variantes / SKU** (tamaños, colores, formatos) — solo si afectan la imagen final.
10. **Reclamaciones específicas** (claims medibles, certificaciones, ingredientes activos con %, garantías).

### Qué NO hacer

- ❌ No inventes features que no estén en la página. Si la URL no lo dice, no lo afirmes en la secuencia de stories.
- ❌ No traduzcas el nombre del producto.
- ❌ No saques claims regulatorios (médicos, "cura", "100% efectivo") aunque la página los diga, salvo que estén respaldados con evidencia visible.
- ❌ No extraigas info de páginas que no sean la del producto (ej: "Nosotros", "Blog") salvo que la URL principal sea pobre.

### Si el scrapeo falla
- Página con bot blocker / login → pedí al user que te pegue el contenido relevante (descripción, beneficios, precio).
- Página con info pobre → pedí al user descripción manual.
- Página en otro idioma → traducí internamente al español pero conservá el nombre original del producto.

---

## Sub-paso 2B: Análisis de la imagen de referencia

### Qué extraer de la imagen

1. **Paleta dominante** — 3 a 5 colores principales con descripción + hex.
   - Identificá: color del producto en sí, color del packaging/etiqueta, color de fondo si está en escena.
   - Convertí cualquier descripción en hex.
   - Ordená de mayor a menor presencia visual.

2. **Tipografía visible** — la(s) familia(s) tipográfica(s) en la etiqueta/packaging.
   - Categoría: serif (qué tipo: humanista, didone, slab), sans-serif (qué tipo: geométrica, humanista, grotesca), display, monospace, script.
   - Características: alto contraste / bajo contraste, condensada / regular / wide, mayúsculas / minúsculas, tracking abierto / cerrado, peso predominante.
   - Si hay dos tipografías en la etiqueta: anotá ambas y cuál es la dominante.
   - **Nunca afirmes un nombre de fuente específico** ("es Helvetica") salvo que estés 100% seguro. Mejor describir características.

3. **Material y acabado del producto** — vidrio (transparente / ámbar / opalino), plástico (mate / brillante), cartón (kraft / coated / texturado), metal (pulido / cepillado / oxidado), tela, cerámica, madera, etc. Esto importa para iluminación.

4. **Forma y proporción** — alto / bajo, ancho / esbelto, redondeado / angular. Importa para el ángulo de cámara y composición.

5. **Estilo visual implícito de la marca** — qué "vibra" da la imagen.
   - Editorial / lifestyle / minimal / maximalist / heritage / clinical / vintage / playful / clinical / industrial / earthy / etc.
   - Una palabra suficiente.

6. **Mood implícito** — calmo, enérgico, lujoso, accesible, técnico, sensorial, etc.

### Si la imagen es pobre

- Imagen muy chica / pixelada → pedí una mejor.
- Imagen sin packaging visible → pedí una con la etiqueta a la vista.
- Imagen con marca de agua / logo del fotógrafo → marcá que el user puede tener problemas de uso.
- Imagen con producto en uso (persona ya usándolo) → es válida, pero pedí también una limpia del producto solo si es posible.

## Sub-paso 2C: Síntesis del brief silencioso

Una vez procesados URL e imagen, armá una **nota mental interna** con esta estructura. **No se la mostrás al user todavía** — la vas a usar para Decisions.

```
PRODUCTO: [nombre exacto]
CATEGORÍA: [categoría]
DESCRIPCIÓN: [1-2 oraciones]
BENEFICIOS CLAVE:
  - [b1]
  - [b2]
  - [b3]
TARGET: [target inferido]
PRECIO / POSICIONAMIENTO: [premium / mid / accesible]
TONO DE MARCA: [una palabra]
ARQUETIPO SUGERIDO: [el que mejor matchea el producto, ver story_archetypes.md]
STORIES SUGERIDAS: [N entre 3-6]
HOOK SUGERIDO: [una frase, max 6-8 palabras]
MODO VISUAL SUGERIDO: [Minimalista / Lifestyle cinematográfico — ver style/visual_modes.md para criterios. Razón en una línea.]
ESTILO VISUAL SUGERIDO: [una palabra, alineada al modo elegido]
MOOD SUGERIDO: [una a dos palabras, alineadas al modo]
LENTE SUGERIDO: [mm + apertura, según el modo: 50mm/85mm para minimalista, 35mm para lifestyle]
TRATAMIENTO DE LUZ SUGERIDO: [una frase, según el modo: softbox neutro para minimalista, cálida lateral 3200K para lifestyle]
PALETA EXTRAÍDA:
  - [color 1] — #hex
  - [color 2] — #hex
  - [color 3] — #hex
  - [color 4] — #hex
TIPOGRAFÍA EXTRAÍDA: [familia + características]
MATERIAL / ACABADO PRODUCTO: [descripción]
PERSONA EN CUADRO: [sí/no/depende de la story]
STICKERS SUGERIDOS POR STORY: [resumen]
```

Esto es tu **brief de trabajo**. Con esto avanzás a Decisions.

---

## Reglas de Discovery

1. **Silencio total** con el user durante este paso. Procesás y avanzás.
2. **Si algo crítico falta** después de scrapear (ej: producto sin descripción), pedilo en Intake-extendido antes de seguir.
3. **No inventes**. Si la página no lo dice, no lo afirmes.
4. **Extraé paleta y tipografía con precisión**. Esto define la coherencia visual de la secuencia entera.
5. **No saltees al Concept**. Decisions va primero — el user tiene que validar antes de generar.
