# Template — Bloques por pieza

Formato de cada bloque dentro del brief. El **brief de imagen** describe la dirección visual; el prompt final lo arma la skill de ejecución.

## Anuncio estático (Meta)

```markdown
### Ad #{n} — {nombre del ángulo}
**Funnel:** {Frío / Tibio / Caliente} · **Formato:** {4:5 / 9:16}
**Primary Text:**
{texto principal — voz de la marca, sin claims inventados}
**Headline:** {≤25 car.}
**Description:** {≤19 car.}
**CTA:** {Comprar / Más info / …}
🖼️ **Brief de imagen:** {concepto/escena + producto en cuadro + mood}
**Producto:** {nombre exacto}
```

## Carrusel

```markdown
### Carrusel #{n} — {tipo/ángulo}
**Funnel:** {…} · **Slides:** {N}
**Copy on-image por slide:**
1. (Hook) "{...}"
2. "{...}"
N. (CTA) "{...}"
**Concepto visual:** {dirección por slide: qué muestra, mood}
**Producto:** {nombre}
```

## Stories

```markdown
### Stories #{n} — {ángulo}
**Frames:** {N}
1. Copy: "{...}" · Sticker: {poll/pregunta/countdown/link/ninguno}
N. Copy: "{...}" · Sticker: {...}
**Concepto visual:** {dirección general}
```

## Video UGC / film

```markdown
### Video #{n} — {ángulo}
**Duración:** {15s/30s} · **Formato:** {9:16 / 1:1}
**Hook (primer 1.5s):** {...}
**Beats / guion:** {3-5 beats o líneas de guion}
**Modelo sugerido:** {Kling / Veo / Seedance} — {por qué}
**Nota:** el detalle fino lo resuelve `ugc-video-prompts` / `all-videos`.
```
