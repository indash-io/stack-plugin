# Self-check — Content Brief

Corré este checklist antes de entregar el brief.

## Contexto y marca
- [ ] Apliqué el gate del MCP `indash` (o avisé qué faltaba).
- [ ] Heredé voz, reglas y paleta del `CLAUDE.md` del cliente + `brand/`.
- [ ] Respeté las reglas duras de la marca en todo el copy (ej: sin precio, sin preventa, voseo).
- [ ] No inventé productos, precios ni claims.

## Plan
- [ ] Confirmé el mix de piezas con el user antes de detallar (una sola pregunta consolidada).
- [ ] Cada pieza declara funnel + formato.
- [ ] Variá ángulos entre piezas del mismo tipo (no variaciones cosméticas).

## Piezas
- [ ] Cada bloque sigue el formato de `templates/piece_blocks.md`.
- [ ] El copy de ads respeta los límites (Headline ≤25, Description ≤19).
- [ ] Los briefs de imagen son dirección visual, no prompts finales.

## Output
- [ ] El brief sigue `templates/brief_template.md`.
- [ ] Lo guardé en `briefs/<AAAA-MM-DD>_<periodo-slug>_v<N>.md` (versiona, no pisa) y dije la ruta.
- [ ] Cerré con el handoff que mapea cada bloque a su skill de ejecución.

Si todo en verde → entregá.
