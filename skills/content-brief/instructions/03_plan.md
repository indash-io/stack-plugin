# 03 — Plan (el mix de piezas)

Acá proponés el **mix de piezas del período** y lo confirmás con el user en UNA sola pregunta consolidada. No detallás piezas todavía.

## Cómo armás el mix

Según el objetivo y el período, proponé cantidades por tipo. Cada tipo apunta a una parte del funnel:

| Tipo | Funnel típico | Para qué |
|---|---|---|
| Anuncios estáticos (Meta) | Frío / tibio | Captar y retargetear; el caballo de batalla de paid |
| Carruseles | Tibio | Educar, mostrar prueba, desarrollar el producto |
| Stories | Tibio / caliente | Ritmo rápido, engagement, urgencia |
| Videos UGC / film | Frío / tibio | Hook fuerte, demo, testimonial |
| Emails | Caliente | Convertir lista propia (promo, lanzamiento, restock) |
| Cambios de catálogo | — | Ajustes de fichas/imagen de producto si el período lo pide |

### Defaults razonables (ajustá al objetivo)

- **Mes estándar**: 8-12 ads, 4-6 carruseles, 4-6 secuencias de stories, 4-8 guiones de video, 2-3 emails.
- **Lanzamiento**: cargá ads + video (frío) y 1-2 emails de hype + 1 de salida.
- **Promo / fecha especial**: cargá emails + stories (urgencia) + ads de oferta.

Justificá el mix en una línea por tipo (por qué esa cantidad para este objetivo).

## Pregunta consolidada

Mostrale al user el mix propuesto y pedí confirmación en un solo mensaje:

> Para **{cliente}** · objetivo **{objetivo}** · período **{período}**, propongo este mix:
> - Ads (Meta): {N} — {razón}
> - Carruseles: {N} — {razón}
> - Stories: {N} — {razón}
> - Videos: {N} — {razón}
> - Emails: {N} — {razón}
> - Cambios de catálogo: {N si aplica}
>
> ¿Lo dejamos así o ajustás cantidades/tipos?

**Siempre confirmás antes de detallar.** Si el user ajusta, actualizás el mix; recién ahí pasás a los briefs por pieza.

Con el mix confirmado → pasá a `04_piece_briefs.md`.
