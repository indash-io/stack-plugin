# Intake — Validación de input

## Inputs REQUERIDOS
1. **Descripción del producto** (qué es, para quién, beneficio principal)
2. **Imágenes del producto** (1+ — packshot, lifestyle, o ambos)
3. **Imágenes de referencia / brandkit visual** (1+ — ads previos, sitio, IG de la marca)
4. **URL de landing**

## Inputs OPCIONALES
- Concepto o ángulo que el usuario ya tiene en mente
- Objetivo de campaña (Awareness, Traffic, Engagement, Leads, Sales, App Promotion)
- Oferta concreta (precio, descuento, bundle, urgencia)
- Audiencia objetivo
- Diferencial vs competencia
- Testimonios / reviews / claims con sustento

## Reglas
- Si falta un input REQUERIDO → preguntar antes de continuar. No asumir.
- Si falta un input OPCIONAL → no preguntar, usar el mejor criterio o inferir.
- Sin imágenes del producto NO hay prompt viable. Pedirlas siempre.
- Sin imágenes de referencia / brandkit NO hay extracción de paleta ni tono. Pedirlas siempre.
- Si el objetivo de campaña no está claro → inferirlo del producto + oferta. Default: **Sales**.

## Antes de pasar al siguiente paso
Confirmar mentalmente que tenés:
- [ ] Sé qué es el producto y qué problema resuelve
- [ ] Tengo al menos 1 imagen del producto
- [ ] Tengo al menos 1 imagen de referencia visual de la marca
- [ ] Tengo la URL de landing
