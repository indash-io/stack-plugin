# Tone of Voice — Copy de Meta

## Default (ajustar según brandkit detectado)
- **Directo**, sin vueltas
- **Conversacional**, no corporativo
- **Beneficio-first**: qué gana el usuario, no qué hace el producto
- **Confiado**, no arrogante
- **Específico**, no genérico

## Calibración según brandkit detectado
- Marca **lujo / aspiracional** → más editorial, frases cortas con peso, menos urgencia, sin descuentos a primer plano
- Marca **accesible / cercana** → voseo, frases coloquiales, humor liviano permitido
- Marca **técnica / clínica** → datos, especificaciones, ingredientes, menos emoción
- Marca **lifestyle / identidad** → narrativa de quién sos al usarla, comunidad
- Marca **fun / juvenil** → ritmo rápido, referencias culturales, emojis si la marca los usa

## Lo que NUNCA hace este skill
- Hablar como AI: *"¡Descubrí cómo nuestro innovador producto puede transformar…"*
- Adjetivos vacíos: *"increíble", "revolucionario", "único", "mejor"*
- Promesas sin números o sin prueba
- Llenar con palabras para "sonar más profesional"
- Copy que podría servir para cualquier producto = copy que no sirve para ninguno
